# 次の字幕まで表示を延長する手順（公開用）

過去の表示時間調整の記録から、再利用に必要な条件を整理しました。今回の字幕を実際に変更・検証した報告ではありません。

## 求める表示

- 各字幕の終了を、次の字幕の開始に合わせる。
- 原則として字幕の文章と開始時刻を維持する。
- 最初の発話前に字幕をさかのぼって表示しない。
- 最後の字幕は、字幕対象となる動画区間の終端まで表示する。後から追加するOP・EDへ無条件に延長しない。

この連続表示は配布プロンプトの初期設定です。長い無発話や場面転換で表示を切りたい場合は、利用者がその例外を指定します。

## 手順

1. 変更前の字幕本文、開始・終了時刻、対象区間の終端、字幕スタイルを記録する。
2. 開始時刻が正しい順番になっていることを確認する。同時刻開始等で不正になる箇所は、単純に延長して済ませない。
3. 各字幕の終了を次の字幕の開始へ合わせ、最後の字幕は対象区間の終端へ合わせる。
4. 実際のfpsと、使用するAPI・字幕形式の終了時刻の扱いを確認して反映する。勝手に1フレームを足し引きしない。
5. 直接変更できない場合は、SRTと一時的な字幕タイムライン等の利用可能な経路を試す。映像・音声のクリップを巻き込んで変更しない。
6. 反映後に本文、開始、終了を読み戻し、変更計画と照合する。
7. 隣接境界で意図しない空白や二重表示がないこと、動画終端を超えないことを確認する。
8. 必要な境界を画面で確認し、書式、映像・音声、ロック状態が維持されているか確認する。

## 報告上の注意

時刻データが一致した確認と、実際の再生で読みやすいと判断した確認を分けます。変更前に書き出したプレビューを、変更後の結果として使わないでください。

一時的なタイムラインや試作字幕を片付ける場合は、今回作成した不要物であることを確認します。復元に必要なデータや、本番タイムラインが参照する素材を削除しません。
