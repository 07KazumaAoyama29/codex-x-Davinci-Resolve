# 字幕作成：短い範囲で試す手順（公開用）

元の字幕試作記録から、再利用に必要な手順と書式を整理しました。個人のプロジェクト、発話本文、参照映像、出力ファイル、使用量履歴は含めていません。

これは今回の利用者の環境で実施済みという報告ではありません。利用可能な操作を確認して適用してください。

## 1. 対象を確認する

- プロジェクト、編集済みタイムライン、尺、解像度、fps、タイムライン開始時刻を取得する。
- 元タイムラインを保持し、複製に字幕を作る。
- 変更前の映像・音声クリップの配置、長さ、素材参照範囲、取得可能な設定、トラックのロック状態を記録する。
- 作業中にロックを変更した場合は、終了時に元の状態へ戻す。

## 2. 現在の編集済み音声を使う

字幕の音声は、現在のタイムラインの発話・順番・時刻に一致するものを使います。タイムラインから必要な範囲の音声を取り出す等、使える経路を選びます。

焼き込み済み音声を使う場合は、現在再生されている音声と一致することを確認します。カット前の素材の文字起こし時刻を、編集後にそのまま流用しません。字幕のために全編映像を再レンダリングすることは必須ではありません。

## 3. 短い範囲で文字起こし・区切りを確認する

1. 言い回しや専門用語を含む短い代表範囲を選ぶ。
2. 現在利用できる文字起こし機能で日本語の発話を取得する。過去の手順ではResolveの文字起こしを使用したが、今回の環境での可否を確認する。
3. 単語や発話の時刻を使って、文節・意味のまとまりで字幕を分ける。文字数比例だけで時刻を推測しない。
4. 「わから／ない」のように単語や活用を不自然に分断しない。
5. 台本で専門用語・固有名詞の表記を確認する。台本にしかない発話を追加しない。
6. 認識誤りか実際の言い間違いか判断できなければ、時刻と理由を残す。
7. ゼロ長、逆転、意図しない重なり、範囲外の時刻を点検する。

この資料の数値や架空例ではなく、今回の発話を使って確認します。

## 4. 配置と書式

以下は過去の実演で使った1920×1080向けの設定を、初期値として記したものです。

| 項目 | 初期値 |
|---|---|
| フォント | Noto Sans JP、Bold |
| 文字 | 白、サイズ58、中央揃え |
| 縁 | 黒、サイズ6、Outside Only |
| 位置 | X=960、Y=80 |
| 背景 | 黒、不透明度75％、角丸0、文字量に応じる幅 |
| 行数・区切り | 1行、全角換算最大24文字を目安に、文節で切り替える |

- フォントファイルや比較用画像は同梱していません。フォントがなければ、利用者に代替または用意する方法を確認します。
- 解像度・画角・画面構成が違う場合は、実際の画面内で読みやすくなるよう調整します。
- 長い字幕や専門用語を含む字幕を実際に表示して、欠け・はみ出し・背景との重なりを確認します。
- SRTにはこの書式は含まれません。SRTの取り込み後、Resolve側で書式を設定し、反映を確認します。
- 1行に収まらなければ、文字を切り捨てず、意味の区切りを見直します。

## 5. SRTとタイムラインの時刻を合わせる

- SRTの時刻は、今回の編集済み動画の先頭を0とする相対時刻で作る。
- 取り込み時には、タイムラインの開始タイムコードと相対時刻の対応を確認する。先頭が1時間等でも、SRTへ無条件にその値を加えない。
- fpsは実際のタイムラインを使う。60fps等へ固定しない。フレームへの変換は使用するAPI・書式の仕様を確認する。
- 正しい位置に字幕が配置されたか、先頭と複数の字幕境界を読み戻して照合する。

## 6. 利用可能な反映方法を選ぶ

過去の環境では、字幕の本文・位置・長さの変更がAPIだけでは完了せず、SRT取り込みと画面操作を併用しました。これは過去の記録であり、現在のすべての環境に同じ制約があるという意味ではありません。

- APIとファイル処理で可能な範囲を先に確認する。
- SRTをメディアプールから対象タイムラインへ挿入する方法、字幕だけの一時タイムラインから対象トラックへコピーする方法など、実際に使える経路を短い範囲で確認する。
- Computer Useが必要なら操作内容と見込み時間を事前に知らせる。利用できなければ、利用者が行う手動操作を具体的に伝える。
- 試行錯誤で元の字幕・映像・音声を削除しない。一時的に作ったものを片付ける場合も、今回作成した不要物か確認する。

## 7. 確認して全編へ進む

- 字幕の本文・開始・終了が作成計画と一致するか確認する。
- 元の映像・音声の配置等が変わっていないか確認する。
- 必要な少数区間を字幕付きで書き出すなど、実際の表示で書式を確認する。APIの値が一致することと、音声に自然に合って見えることは別に扱う。
- 耳で確認できなかった場合は、利用者による確認が必要な箇所を残す。
- 問題なければ[全編作成](../subtitle_full/report.md)へ進む。表示時間は[延長手順](duration_adjustment/report.md)に従う。
