# DaVinci Resolve × Codex 編集プロンプト

DaVinci ResolveをCodexから操作して、カット編集・音声処理の焼き込み・日本語字幕作成を依頼するためのプロンプトと参照資料です。

動画で使用した改善済みプロンプトを基に、初めて使う人へ渡せるよう、個人用パスと過去の制作データへの依存を整理しました。**動画使用版を公開向けに調整した資料集**であり、元の会話やファイル一式をそのまま公開したものではありません。変更点は[CHANGELOG.md](CHANGELOG.md)に記載しています。

- [GitHubリポジトリ](https://github.com/07KazumaAoyama29/codex-x-Davinci-Resolve)
- [ファイル一式をZIPでダウンロード](https://github.com/07KazumaAoyama29/codex-x-Davinci-Resolve/archive/refs/heads/main.zip)

## 最初に使うファイル

- [カット編集＋音声の焼き込み](cut.md)
- [日本語字幕作成](subtitles.md)

各ファイルのコピー用プロンプトを使ってください。参照する手順書はすべてこのフォルダに入っています。動画・台本は利用者自身のものを用意します。

## 用意するもの

- DaVinci ResolveとCodexが接続できる環境。元の実演環境はDaVinci Resolve Studio 21.1です。無料版の対応や他バージョンでの同等動作は、この資料では確認していません。
- 編集対象のプロジェクト・タイムライン・オンライン状態の素材。
- 話し言葉の台本やメモ。添付するか、Codexが読める場所を指定します。なければ「なし」に置き換えます。
- この資料フォルダを読み取れるCodexの作業環境。
- 出力音声等を保存する、削除予定のない作業フォルダ。この配布フォルダとは別の場所を推奨します。

これはプロンプトと手順の配布です。MCPサーバー、専用Skill、実行プログラム、フォントは同梱していません。接続済みの機能を確認し、その環境で使えるAPI・ファイル処理・必要に応じた画面操作で進める依頼になっています。旧素材向けスクリプトは利用の必須条件ではありません。

## 使い方

1. 上のリンクからZIPをダウンロードし、フォルダごと展開します。展開後のフォルダ名が異なっていても、README.mdがある場所を資料フォルダとして使います。
2. Codexに、このフォルダを読み取れる場所として渡します。フォルダを指定できる環境では、展開したフォルダを選んでください。別の場所から作業する場合は、プロンプト先頭の「資料フォルダ」を実際の場所に置き換えます。
3. Resolveで編集対象を開き、Codexに現在のプロジェクト名・タイムライン名を取得させ、対象を確認します。
4. 必要なノイズ除去等を先に設定します。[cut.md](cut.md)の入力欄を埋め、コピー用プロンプトを送ります。カット後の音声焼き込みも含みます。
5. 結果を再生して確認し、必要な修正や画像・効果音の追加を行います。
6. [subtitles.md](subtitles.md)の入力欄を埋め、コピー用プロンプトを送ります。
7. 字幕の内容・タイミング・見た目を確認し、OP・EDや音声の仕上げなどを行います。

ファイルを添付する方法で使う場合も、プロンプトから参照する同梱資料をすべて読める状態にしてください。プロンプト本文だけを渡して、資料を読んだことにして進めないでください。

ZIPの取得方法：[GitHub公式説明](https://docs.github.com/en/repositories/working-with-files/using-files/downloading-source-code-archives)

## 調整する項目

- プロジェクト、タイムライン、台本、出力用作業フォルダ。
- 最後の完成テイクを優先する方針、残したい間、字幕のフォント・大きさ・背景。
- カット＋焼き込みの使用量目安。初期値は15ポイント未満、11ポイントで見直し、14ポイントで新しい追加作業を止める設定です。処理中に15ポイント到達を確認した場合も、未完了のまま引き渡します。
- 使用量を取得できない環境では、予算を確認できる手段と継続範囲を決めてから進めます。表示の取得間隔や処理中の消費があるため、15ポイント以内の完成や厳密な自動停止を保証する仕組みではありません。
- 字幕プロンプトには固定の使用量上限を設けていません。上限が必要な場合は開始前に追加してください。

使用量の「ポイント」は、同じ対象枠の使用率表示の差です。残量に対する割合や料金への換算ではありません。別作業の同時利用やリセットをまたぐ場合、その編集だけの消費として単純計算しないでください。

## 確認すること

- 編集先は元タイムラインの複製です。利用者が保持している元の映像・音声を上書きする依頼ではありません。
- 音声焼き込みで作ったファイルは、タイムラインが参照します。再生に必要なので作業後も保持してください。
- 字幕作成では、現在の編集済みタイムラインと一致する音声を使います。
- 音声・映像を実際に確認できなかった項目は、AIの報告でも未確認として残します。
- 配布用に整理したこの一式を使った、新規環境での編集完走テストは未実施です。まず短い範囲で確認してください。具体的な使用量や品質は保証していません。

公開前の確認結果は[PUBLICATION_REVIEW.md](PUBLICATION_REVIEW.md)に記録しています。正式なライセンスはこの版では未設定です。
